# 🎓 Campus Buddy — Student Task Manager

Welcome to **Campus Buddy**, a clean, modern, and mobile-friendly task management web application designed specifically for college students!

---

## 🚀 Features

1. **Add Tasks**: Quickly record your study tasks, homework, and deadlines.
2. **Task Details**: Include task name, due date, category (Assignment, Exam Prep, Lab, Project), and priority level (High, Medium, Low).
3. **View & Filter Tasks**: View all tasks or filter them by **All**, **Pending**, or **Completed**.
4. **Mark Completed**: Check off tasks as you finish them with instant visual feedback.
5. **Delete Tasks**: Remove tasks you no longer need.
6. **Live Progress Stats**: Real-time counter of total, pending, and completed tasks.
7. **Responsive Design**: Looks great on mobile phones, tablets, and laptops.

## 💻 How to Run This Project Locally

As a beginner, you have two super easy ways to run this:

### Option 1: Direct Double-Click (Easiest)
1. Open your File Explorer on Windows.
2. Navigate to `C:\Study Planner`.
3. Double-click **`index.html`**.
4. It will immediately open and run in your default web browser (Chrome, Edge, etc.)!

### Option 2: Using VS Code "Live Server" (Recommended for Developers)
1. In VS Code, go to the **Extensions** tab (`Ctrl + Shift + X`).
2. Search for **Live Server** (by Ritwick Dey) and click **Install**.
3. Right-click on `index.html` in your file tree and choose **"Open with Live Server"**.
4. Any changes you make to the code will automatically reload in your browser!
